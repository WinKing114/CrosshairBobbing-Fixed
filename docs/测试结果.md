## 2. 构建测试（通过）

3. **最终构建**：`gradle buildMod --no-daemon --console=plain --stacktrace` → **BUILD SUCCESSFUL in 6m40s**，143 个任务（128 executed / 15 up-to-date），`GRADLE_EXIT=0`。12 个 MC 版本实现全部编译、`validateApi` 全通过、`buildMod` 产出 3 个 JAR。证据 `research/fixed-build-3.log`。
4. 产物：`CrosshairBobbingMod/dists/CrosshairBobbing-1.10.1.jar`（主 JAR）、`-dev.jar`、`-sources.jar`。

构建环境：JDK 17（Zulu 17）运行 Gradle 7.6；项目 toolchain 由 Gradle 自动配置（JDK 8/16 等已自动下载）。

## 4. 功能与体验（通过，含主观视觉判断）

- **HUD 正常**：整屏截图显示准星居中、热键栏水平无倾斜/偏移，未见血条/其它 HUD 元素被准星变换误带动。
- **准星跟随摇晃**：测试实例 `options.txt` 设 `bobView:true`；通过窗口激活 + 按住 W 键移动，截取准星中心区域 5 张序列图（`anim-0-idle` → `anim-3-move` → `anim-4-after`）。视觉对比：静止时准星位于中心，移动时准星偏移数像素并伴随轻微形态变化，世界背景同步变化证明移动生效；停止后回位。这符合"准星跟随视角摇晃"的原设计。
  - 用像素质心做的辅助统计受雪地背景深色像素干扰（darkPixels 134→326），**不作为严格量化结论**，仅以截图视觉对比为准。

## 7. 结论

- 交付 JAR 可正常构建、可在 Minecraft 1.20.1 Forge 中加载并进入世界，核心功能（准星跟随视角摇晃）在游戏内可见，HUD 无异常。
- 已确认的两处启动崩溃根因（Quilt 反射注入、Quilt 误判）在代码与产物字节码层面修复；由于缺少对应环境，未做运行时复现，按限制说明。
- 配置损坏导致的模组静默失效、失效的 TaCZ Fabric 编译依赖、构建阻塞、HUD 注入点跨版本脆弱性等问题已有静态或游戏内证据。
- 未验证项见第 6 节，不宣称"所有 issue 全部修复"。详细修复内容见 `修复记录.md`，研究证据见 `research/`。
