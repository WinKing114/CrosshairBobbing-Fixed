[English](README.md)

开启「视角摇晃」后，准星会跟着脚步轻摆。攻击、挖掘、进食或为弓弩蓄力时，准星也会随动作变化，各项动画可以单独开关。

在 Forge 1.20.1 上，攻击指示条随准星移动，血条和快捷栏保持原位。1.11.0 重复利用动画缓冲区，并沿用你原有的设置。

本次发布面向 Minecraft 1.20.1 / Forge。将 JAR 放入客户端的 mods 文件夹，替换原版 Crosshair Bobbing。原作由 Krash220 开发，本分支沿用 GPL-3.0-only 许可证。
